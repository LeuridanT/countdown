# Gothic Romance Countdown

A dark, elegant gothic romance countdown website to February 7, 2027.

Two hearts slowly drift closer together as time passes. When the countdown reaches zero, they meet in the center.

## Features

- Countdown in days, hours, and minutes
- Gothic aesthetic (deep blacks, burgundy, antique gold accents)
- Elegant typography (Cinzel + Cormorant Garamond)
- Animated hearts that move closer based on time remaining
- Subtle particle effects
- Responsive design

## Files

- `index.html` — Main page structure
- `style.css` — All styling
- `script.js` — Countdown logic and heart animation

## How to use

1. Clone or download this repository
2. Open `index.html` in a browser

Or host it on GitHub Pages for a live version.

## Customization

To change the target date, edit the `targetDate` variable in `script.js`.

```js
const targetDate = new Date('2027-02-07T00:00:00').getTime();
```
